Formulario recibido

¿Dónde están los datos que cargaste?

Mirá la barra de direcciones de esta pestaña. Vas a ver algo como:

respuestaFormulario.html?apellido=Perez&nombre=Juan&correo=juan@mail.com&sexo=m&Estudios=uni

Eso pasa porque el formulario se envió con method="get": todas las variables input con sus valores viajan en la URI del requerimiento, después del signo de pregunta y separadas por &. El nombre de cada variable es el que pusimos en el atributo name de cada input.

Cosas para observar

  • Los checkbox que no tildaste no aparecen en la URL: si no se chequean, esa variable no viaja.

  • El input hidden (codigoDeFormulario=ejer03) si aparece, aunque nunca lo viste en pantalla.

  • De los radio viaja una sola variable (sexo), porque todos comparten el mismo name.

  • Si el método fuera post, la URL se vería limpia: los datos irían en el body del requerimiento y habría que mirarlos con las herramientas de desarrollador del navegador (pestaña Network).
