Variables de tipo objeto

1) Que se practica aca

Ademas de los objetos del BOM y del DOM, JavaScript maneja objetos de estructura de datos: colecciones clave:valor que construye el programador (pag. 5 y 6 del apunte). Cada persona es un objeto {nombre, apellido, fechaNac} y todas se guardan en un arreglo de objetos, solo en memoria.

Los datos ya no se ingresan con prompt sino en los inputs. Crear persona valida los tres campos con checkValidity(), la agrega al arreglo con push() y la presentacion se arma recorriendo el arreglo con forEach() y escribiendo en innerHTML.

2) Probalo

3) Las instrucciones que hacen el trabajo

  • let objetoPersona = {nombre:"Pablo", apellido:"Galdi", fechaNac:"01/07/1956"}; → objeto con pares clave:valor.
  • let arregloPersonas = [objetoPersona]; y arregloPersonas.push({...}); → arreglo de objetos.
  • var objetoPersonas = { personas: arregloPersonas }; → objeto final que contiene al arreglo (pag. 7).
  • objetoPersonas.personas.forEach(function(item, indice) { ... }); → recorre el arreglo; en cada ciclo item es una persona.
  • document.getElementById('presentacion').innerHTML = texto; → escribe HTML sin usar document.write() (pag. 9).
  • style.display = "none" / "block" → oculta y muestra la presentacion (pag. 10).
