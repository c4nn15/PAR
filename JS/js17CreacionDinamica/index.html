Creacion de objetos

1) Que se practica aca

Aca no se trata de mostrar y ocultar con display: los objetos del DOM se crean de la nada con document.createElement() y se agregan al contenedor con appendChild() (pag. 17 del apunte).

JavaScript no tiene un comando clasico para borrar de un saque todo lo que hay dentro de un contenedor, asi que Limpiar hace un barrido y los va eliminando uno por uno con removeChild() (pag. 18). Info recorre el array childNodes del contenedor.

2) Probalo

Usa los botones de la esquina superior derecha. Cuando haya muchos elementos, el contenedor se escrolea.

3) Las instrucciones que hacen el trabajo

  • var objDiv = document.createElement("div"); → crea en memoria un nuevo objeto del DOM.
  • objDiv.innerHTML = textoHtml; y objDiv.className = "claseObjetoDinamico"; → contenido y clase de estilo, todavia solo en memoria.
  • document.getElementById("contenedor").appendChild(objDiv); → lo agrega al contenedor y lo convierte en elemento HTML.
  • childNodes.length → cantidad de nodos hijos del contenedor.
  • while (contenedor.childNodes.length > 0) { contenedor.removeChild(contenedor.childNodes[0]); } → borra siempre el primer nodo hasta que no quede ninguno.
  • Otras formas de vaciar el contenedor (pag. 19): replaceChildren() sin argumento, o innerHTML = "", menos eficiente porque obliga a iniciar el parser.
