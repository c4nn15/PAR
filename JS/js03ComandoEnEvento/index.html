Comando en un atributo de evento

1) Que se practica aca

Otro lugar donde se puede escribir JavaScript es como valor de un atributo de evento de una etiqueta HTML, por ejemplo onclick="" (pag. 12 del apunte). Es lo mismo que escribir CSS dentro de un atributo style.

Dentro del atributo las comillas son dobles, asi que el texto que va adentro del comando se escribe con comillas simples, para no cortar el valor del atributo.

Importante: es valido, pero mezclar HTML y JavaScript no es aconsejable. A partir del ejercicio 7 se reemplaza por addEventListener() al final del documento (pag. 17).

3) Escritura sobre un nodo de texto

Una vez cerrado el flujo de escritura ya no se puede usar document.write(), porque pisaria el documento original. Para escribir dentro de un evento se busca el elemento con document.getElementById() y se le cambia la propiedad innerHTML (pag. 13).

4) Las instrucciones que hacen el trabajo

  • onclick="codigo" → atributo de evento: guarda el codigo a ejecutar al hacer clic sobre la etiqueta.
  • document.getElementById('resultado') → metodo aplicado al objeto document (el primero del DOM) que recibe el valor del atributo id y devuelve el objeto del DOM buscado.
  • .innerHTML = '...' → propiedad que reemplaza el contenido HTML de ese elemento.
