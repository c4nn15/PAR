Operaciones sobre un input

1) Que se practica aca

El elemento <input> del HTML es, dentro de JavaScript, un objeto del DOM. Se lo consigue con document.getElementById("x") y lo que escribio el usuario esta en su propiedad value (pag. 16 del apunte).

Ese value es siempre de tipo string, aunque el usuario haya escrito un numero. Para poder operar aritmeticamente hay que convertirlo con parseInt() (pag. 18). Si no lo hacemos, el operador + concatena en lugar de sumar: probalo con el segundo boton.

Ademas, aca ya no se usa el atributo onclick: el manejador del evento se define con addEventListener() en el archivo script.js, que esta separado del HTML (pag. 17).

3) Las instrucciones que hacen el trabajo

  • document.getElementById("x") → devuelve el objeto del DOM cuyo id es "x".
  • .value → propiedad con el valor que introdujo el usuario. Siempre string.
  • parseInt(...) → recibe un string y lo convierte en tipo numerico. parseInt("40 grados") devuelve 40.
  • addEventListener("click", function() { ... }) → asocia una funcion anonima al evento click del boton.
