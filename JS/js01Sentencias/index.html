Primeras sentencias

1) Que se practica aca

El codigo JavaScript se escribe dentro de un marco de etiquetas <script> del documento HTML (pag. 10 del apunte). El interprete es el propio navegador, asi que no hay nada que compilar: alcanza con abrir este archivo.

Se practican las dos sentencias mas basicas: alert(), que muestra un mensaje en una ventana modal sobre el view port y detiene la ejecucion hasta que el usuario la cierra, y document.write(), que agrega HTML dinamicamente al documento mientras el flujo de escritura sigue abierto.

2) Texto escrito directamente en HTML

Este parrafo lo escribio el HTML, sin ayuda de JavaScript.

3) Texto escrito desde JavaScript

4) Las instrucciones que hacen el trabajo

  • <script type="text/javascript"> → el marco donde vive el codigo dentro del HTML (pag. 10).
  • alert("mensaje") → ventana modal para mostrar texto o el estado de una variable en cualquier parte del programa.
  • document.write("<p>...</p>") → escribe HTML en el documento. Solo sirve fuera de cualquier evento y antes de que termine el flujo de lectura del navegador.
  • // y /* */ → comentarios de una linea y de varias lineas (pag. 9).
