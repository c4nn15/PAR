Operaciones entre inputs

1) Que se practica aca

Lo mismo que en el ejercicio anterior pero con dos operandos: se leen los dos inputs, se convierten los dos con parseInt() y se aplican los operadores de operacion aritmetica del apunte (pag. 9): +   -   *   /   %.

Cada boton tiene su propio manejador de evento definido con addEventListener() dentro de script.js. El resultado se escribe en el div de abajo con innerHTML.

2) Probalo

3) Las instrucciones que hacen el trabajo

  • parseInt(document.getElementById('a').value) → se aplica a los dos operandos, no a uno solo.
  • + - * / % → operadores de operacion aritmetica. El % da el resto de la division entera.
  • isNaN(valor) → pregunta si la conversion fallo, para avisarle al usuario en lugar de mostrarle un resultado roto.
  • if / else → expresion condicional, con el bloque de codigo entre llaves.
