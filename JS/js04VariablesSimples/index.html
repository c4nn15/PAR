Variables simples

1) Que se practica aca

Las variables de JavaScript son de tipado dinamico: pueden cambiar su tipo en tiempo de ejecucion. Y el lenguaje es de tipado debil, porque permite operar entre variables de distinto tipo (pag. 14 del apunte).

Eso ultimo tiene su lado riesgoso: si a vale 1 (number) y b vale "1" (string), la operacion a + b no da 2, da "11", porque el navegador convierte el numero a texto y concatena. Esa conversion automatica se llama coercion de tipos (pag. 2) y no avisa nada: es un error que hay que prevenir a mano.

3) Las instrucciones que hacen el trabajo

  • var a = 1; → declaracion y asignacion. Hecha al principio del programa y fuera de toda funcion, el alcance es global y podra usarse en todas las funciones.
  • typeof a → operador que devuelve el tipo de la variable: number, string, undefined, object...
  • "texto" + variable → el operador + concatena variables con textos HTML cuando alguno de los dos es string.
  • parseInt("40 grados") → devuelve 40. Es la forma de asegurarse de estar operando con numeros (pag. 7).
