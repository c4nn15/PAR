Funciones compartidas

1) Que se practica aca

Una funcion con nombre se puede invocar desde cualquier lugar del programa (pag. 19 del apunte). Recibe argumentos con los cuales opera y devuelve un valor con return.

Aca hay una sola funcion, mayor(arg1, arg2), que devuelve el mayor de dos numeros, y esta compartida por dos procedimientos de evento distintos: el boton de comparar y el boton que la usa para buscar el mayor de tres valores. Escribir la logica una sola vez es lo que hace que la funcion sea reutilizable.

Las variables declaradas con let adentro de la funcion tienen alcance de bloque: desaparecen cuando se cierra la llave. Eso es lo que le da modularidad (pag. 6).

2) Probalo

3) Las instrucciones que hacen el trabajo

  • function mayor(arg1, arg2) { ... } → declaracion de una funcion con nombre que recibe dos argumentos.
  • if (arg1 >= arg2) → expresion condicional con un operador de comparacion (pag. 8).
  • return arg1; → valor retornado. Corta la ejecucion de la funcion y devuelve ese valor a quien la invoco.
  • mayor(mayor(a, b), c) → la misma funcion invocada dos veces, anidada, para resolver el caso de tres numeros.
  • let var1 = parseInt(arg1); → si hay que operar aritmeticamente, los argumentos se pasan ya convertidos o se convierten adentro de la funcion.
