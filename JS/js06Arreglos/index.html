Arreglos de indice numerico

1) Que se practica aca

Un arreglo se declara vacio con [] y resulta de tipo object. Sus elementos se acceden por un indice numerico que arranca en cero: el primero es arregloFrutas[0] (pag. 15 del apunte).

El tercer elemento no viene del programa: lo carga el usuario con prompt(), la funcion que permite ingresar un valor desde el teclado. Igual que el alert(), se ejecuta al principio y detiene toda la ejecucion hasta que el usuario la termina, porque se dispara antes de que se despliegue el resto del documento.

3) Las instrucciones que hacen el trabajo

  • var arregloFrutas = []; → declaracion del arreglo vacio.
  • arregloFrutas = ["banana", "manzana"]; → asignacion de elementos de tipo string.
  • .push(valor) → metodo que agrega un elemento nuevo al final del arreglo.
  • prompt("texto") → ventana modal que devuelve lo que el usuario escribe. Lo que devuelve siempre es un string.
  • arregloFrutas[0] → primer elemento, por indice numerico.
  • .length → devuelve la cantidad de elementos del arreglo.
