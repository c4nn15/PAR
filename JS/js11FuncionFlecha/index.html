Funcion flecha

1) Que se practica aca

Las tres maneras de declarar una funcion que muestra el apunte (pag. 20), escritas una al lado de la otra para ver que hacen exactamente lo mismo. En los tres casos la invocacion es identica: let resultado = suma(a, b);

  • function sumaTradicional(a, b) { return a + b; } → declaracion clasica, con nombre.
  • const sumaAnonima = function(a, b) { return a + b; } → funcion anonima guardada en una constante. Se usa const porque no queremos reasignarla en todo el ciclo de ejecucion del script: es ideal para declarar funciones.
  • const sumaFlecha = (a, b) => { return a + b; } → funcion flecha, la forma nueva de definir funciones a partir de ES6. Es muy parecida al caso anterior: se saca la palabra function y se agrega la flecha => despues de los parametros.

3) Detalle

El manejador del boton tambien esta escrito con una funcion flecha, en lugar de la funcion anonima function() { ... } que veniamos usando. Las dos formas son validas como argumento de addEventListener().

Una diferencia importante: dentro de una funcion flecha no se puede usar this para referirse al elemento que recibio el evento, como haciamos en el ejercicio 10. Por eso ahi la funcion tiene que ser una funcion anonima tradicional.
