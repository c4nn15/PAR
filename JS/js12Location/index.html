Objeto location del BOM

1) Que se practica aca

El BOM (Browser Object Model) es la estructura orientada a objetos que representa elementos del navegador: la ventana, la URL, las cookies, el historial de navegacion (pag. 1 del apunte). JavaScript permite programar tanto sobre el DOM como sobre el BOM.

El objeto principal del BOM es window, la ventana donde corre el navegador. De el cuelgan location (la URL), console y navigator (informacion de configuracion del navegador).

Asignarle un valor a location.href provoca una redireccion a otro host o dominio por JavaScript (pag. 21).

Por seguridad, JavaScript solo puede modificar objetos del DOM y del navegador: no tiene instrucciones que permitan tocar los recursos del equipo local donde corre.

4) Las instrucciones que hacen el trabajo

  • location.href = "https://www.youtube.com"; → asignacion que provoca la redireccion.
  • location.href (leido) → la URL completa del documento actual.
  • location.protocol y location.pathname → partes de esa URL. Abriendo el archivo con doble clic el protocolo es file:.
  • location.reload() → metodo que vuelve a cargar el documento.
  • window.navigator.userAgent → informacion de configuracion del navegador.
