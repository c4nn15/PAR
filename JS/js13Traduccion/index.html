1) Que se practica aca

El objeto window.navigator del BOM tiene las propiedades del navegador. Entre ellas, window.navigator.languages es un array con los lenguajes declarados en la configuracion; el primer elemento es el default language y es de tipo string (pag. 1 del apunte).

Con substr(0, 2) nos quedamos con las dos primeras letras ("es-AR" → "es", "en-US" → "en", pag. 3) y con un condicional elegimos en que idioma se escribe el titulo.

2) Probalo

En el navegador: Configuracion → Idiomas. Subi el ingles arriba de todo de la lista y recarga esta pagina con F5: el titulo tiene que aparecer en ingles. Volve a subir el espanol para dejarlo como estaba.

4) Las instrucciones que hacen el trabajo

  • window.navigator.languages[0] o bien window.navigator.language → el idioma default, tipo string.
  • cadena.substr(inicio, longitud) → devuelve un pedazo del string.
