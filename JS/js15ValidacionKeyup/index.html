Validacion de un input de formulario en el evento onkeyup

1) Que se practica aca

Hasta ahora la validacion HTML5 ocurria al enviar el formulario. Aca la misma validacion se ejecuta desde JavaScript con checkValidity() en el evento keyup: cada vez que se suelta una tecla (pag. 13 del apunte).

Los botones no son de tipo submit ni reset: el formulario se envia y se resetea desde JavaScript con los metodos submit() y reset() (pag. 12).

2) Probalo

Escribi 1, despues 5 (queda 15, valido) y despues otro 5: 155 esta fuera de rango, aparece la alerta y el input se blanquea.

3) Las instrucciones que hacen el trabajo

  • objDia.addEventListener("keyup", function() { ... }); → handler que se ejecuta al levantar el dedo de la tecla.
  • if (!objDia.checkValidity()) → true si el input NO cumple con la validacion HTML5 (min, max, step, required).
  • document.getElementById("miform").method = "get"; y .action = "./respuestaFormulario.html"; → atributos del formulario asignados dinamicamente.
  • document.getElementById("miform").submit(); / .reset(); → envio y reset desde JavaScript.
