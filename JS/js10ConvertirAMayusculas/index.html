Convertir a mayusculas

1) Que se practica aca

Una funcion anonima asociada al evento focusout, que es el cambio de foco de un input: se dispara cuando el usuario sale del campo, ya sea con un clic afuera o con la tecla Tab (pag. 18 del apunte).

Adentro del manejador usamos la palabra clave this, porque el mismo objeto sensible al evento es el que cambia su propiedad value. Asi el codigo no depende del id del campo y se puede repetir tal cual en otro input.

3) Las instrucciones que hacen el trabajo

  • addEventListener("focusout", function() { ... }) → funcion anonima que define el procedimiento para el cambio de foco del input.
  • this → representa al mismo objeto del DOM que recibio el evento.
  • this.value = this.value.toUpperCase(); → metodo de transformacion a mayusculas aplicado sobre el propio valor del campo.
  • .toLowerCase() → el metodo inverso, pasa todo a minusculas.
