Alcance de las variables

1) Que se practica aca

Las tres palabras clave para declarar variables no se diferencian por el tipo de dato, sino por el alcance (pag. 5 y 6 del apunte):

  • var → alcance global o local segun donde se declare, si es afuera o adentro de una funcion. Se puede redeclarar y reasignar. Es la forma mas flexible, pero tambien la mas peligrosa.
  • let → alcance a nivel de bloque, o sea el codigo delimitado por llaves { } de un if o de un bucle. Se reasigna sin problema dentro del ambito, pero no se puede redeclarar. Por eso es la que mas se usa.
  • const → alcance de bloque, y no admite ni redeclaracion ni reasignacion. Si se intenta, aparece el error en la consola del navegador.

Ojo con la trampa: si dentro de una funcion se hace una simple asignacion sin declarar, la variable queda creada con alcance global (pag. 6 y 7).

2) Que paso al ejecutar

Los mismos resultados estan mandados a la consola con console.log(): abrila con F12 para verlos.
