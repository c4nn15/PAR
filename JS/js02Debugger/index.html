Debugger y consola

1) Que se practica aca

Todos los navegadores modernos traen un conjunto de herramientas para desarrolladores (dev tools) que permiten inspeccionar el HTML, el CSS y las instrucciones de JavaScript que estan cargadas, y ademas detectar y depurar errores en tiempo de ejecucion (pag. 11 del apunte).

Abri las herramientas con la tecla F12 (o clic derecho → Inspeccionar) y anda a la solapa Console. Recarga la pagina y vas a ver ahi todo lo que este script mando con console.log().

2) Que se mando a la consola

  • Un mensaje de texto suelto.
  • El contenido de dos variables.
  • El tipo de cada una, obtenido con el operador typeof.
  • Un error provocado a proposito, atrapado con console.error().

A diferencia del alert(), la consola no interrumpe la ejecucion del programa: es la forma comoda de ir mirando el estado de las variables mientras el script corre.
