Ventana modal

1) Que se practica aca

Una ventana modal son en realidad DOS elementos: el contenedor principal de la pagina, y el div modal que aparece por encima. Al abrir el modal, el contenedor de fondo se tiene que desactivar: se le baja la opacidad y se le corta la sensibilidad a los clicks con pointer-events: none, para que no se pueda interactuar con lo de atras mientras el modal esta abierto (pag. 8 y 9 del apunte de especiales).

El modal en si usa visibility en lugar de display: hidden lo saca de la vista pero, a diferencia de display:none, sigue ocupando su lugar (aca no afecta porque esta position:fixed).

Los cuatro estados son clases CSS (contenedorActivo, contenedorPasivo, ventanaModalApagado, ventanaModalPrendido) que JavaScript asigna con className. En la version jQuery se usaria en cambio el metodo attr("class", ...).

Adentro del modal va el mismo formulario de ALTA de esp05 y esp20, con su <select> de sucursal poblado desde sucursales.js. Este ejercicio no tiene tabla ni arreglo de clientes en memoria: apretar ENVIAR solo confirma los datos cargados con un alert() y cierra el modal (la version que ademas guarda el cliente en un arreglo y lo agrega a una tabla es esp20).

3) Las instrucciones que hacen el trabajo

  • document.getElementById('contenedor').className = "contenedorPasivo"; → desactiva el fondo.
  • document.getElementById('ventanaModal').className = "ventanaModalPrendido"; → muestra el modal.
  • div.contenedorPasivo { opacity: 0.3; pointer-events: none; } → transparencia y bloqueo de clicks del fondo.
  • div.ventanaModalPrendido { visibility: visible; } / div.ventanaModalApagado { visibility: hidden; } → muestra u oculta el modal.
  • $(window).width(); → objeto del BOM en jQuery: ancho actual del viewport, mostrado con un alert() al abrir el modal.
  • poblarSelectSucursales() → la misma funcion de esp05: recorre el arreglo de sucursales con forEach() y arma las <option> del select con document.createElement("option").
  • $("#btEnviar").click(function() {...}); → arma el objeto cliente con los valores del formulario y lo muestra con alert(JSON.stringify(...)), sin guardarlo en ningun lado.
