Selectores de clase y de id

1) Parrafo sin clase

Este parrafo no lleva atributo class. Sirve como referencia para comparar contra los que si lo llevan.

2) Parrafos con el atributo class

Este parrafo pertenece a la clase claseAcotacion: va centrado, en italica, en azul y con un borde fino alrededor.

Este otro parrafo tambien pertenece a claseAcotacion y por eso se ve exactamente igual que el anterior.

Este parrafo pertenece a claseDestacada: otra clase, otro estilo.

3) Estilos en cascada

Este parrafo esta anidado dentro de un div de clase claseCaja. No tiene ningun class propio, pero igual se ve en violeta: hereda el color de su elemento contenedor.

Este otro parrafo tambien esta anidado en el div, pero como tiene su propia clase, el color verde de claseDestacada le gana al violeta que venia heredando en cascada.

4) Selector de id (un unico elemento)

Este es el unico parrafo del documento con id="parrafoUnico", por eso es el unico que toma este estilo.
