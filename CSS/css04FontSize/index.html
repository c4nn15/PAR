Tamaños de letra: px, %, vw y em

Las unidades de medida disponibles

  • px: fijo en pixeles (el mas comunmente usado)
  • %: porcentual respecto al tamaño del contenedor padre
  • vw: porcentual respecto al view-port (la ventana del navegador)
  • em: cantidad de veces el tamaño de letra base del documento

Un parrafo por unidad

font-size: 24px → siempre mide 24 pixeles.

font-size: 150% → una vez y media el tamaño del contenedor padre.

font-size: 2vw → el 2% del ancho de la ventana. Agranda y achica la ventana del navegador: este es el unico parrafo que cambia de tamaño.

font-size: 2em → el doble del tamaño base del documento.

Cuidado: el em se acumula en cascada

Este texto suelto dentro del div mide 2em (32px).

Y este parrafo anidado pide otros 2em, pero medidos sobre el div, no sobre el documento: termina midiendo 64px.
