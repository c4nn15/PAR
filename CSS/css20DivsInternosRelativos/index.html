Posicionamiento relativo y posicionamiento fijo

1) Que se practica aca

Con position:relative (pag. 2 del apunte) cada contenedor se ubica respecto al contenedor anterior: el margen izquierdo es la coordenada en X respecto al borde del padre, y el margen superior es la coordenada en Y respecto al borde inferior del div que viene antes.

Con position:fixed (pag. 3 del apunte) el contenedor se ata al viewport: no se mueve aunque el resto del documento scrollee. Es la base de una ventana modal. Scrolleá esta página y mirá el recuadro del medio.

Ventana modal

Este contenedor tiene position:fixed, asi que queda pegado al viewport mientras todo lo demás scrollea por debajo.

Tiene además opacity:0.5, por eso se transparenta lo que pasa atrás, y un z-index alto para quedar por encima de todo.
