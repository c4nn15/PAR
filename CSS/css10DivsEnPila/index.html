Divs apilados uno debajo del otro

Que se practica aca

Ningun div de esta pagina tiene el parametro float, asi que cada uno arranca en una linea nueva, por debajo del anterior. Es el comportamiento natural de los div.

Caja 2

Caja 3

Esta caja tiene un alto fijo de 150px, asi que ya no crece con su contenido.

Como el contenido no entra, el overflow en auto le agrega una barra de scrolling a la derecha para poder barrerlo completo.

Este ultimo parrafo esta aca justamente para que el contenido no entre y se vea la barra.
