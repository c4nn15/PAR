Menú de opciones desplegable

1) Que se practica aca

Este menú es un índice alternativo de toda la materia, armado únicamente con dos listas anidadas y CSS: no hay una sola línea de JavaScript.

Pasá el mouse por encima de HTML o de CSS y se despliega la lista vertical. El fondo de cada opción cambia con el :hover, tanto en el menú horizontal como en los desplegables.

2) Como funciona

  • #menu ul li { float:left } → los ítems del menú principal se acomodan en fila (pag. 8).
  • #menu ul li { position:relative } → como el desplegable se ubica de manera absoluta, el li que lo contiene tiene que ser relative para actuar como padre y darle el origen de coordenadas.
  • #menu ul ul { display:none } → toda lista dentro de otra lista es un submenú, y por default no está visible ni ocupa lugar (pag. 9).
  • #menu ul ul { top:100%; left:0 } → el desplegable arranca justo por debajo del ítem horizontal y alineado con su borde izquierdo.
  • #menu ul li:hover ul { display:block } → se lee: toda lista que esté dentro de un li con el mouse encima, y que a su vez esté dentro de una lista del menú principal (pag. 10).
